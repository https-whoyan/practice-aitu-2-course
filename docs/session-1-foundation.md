# Сессия 1 — Фундамент (~35%)

**Цель:** рабочий каркас, на котором можно строить фичи. К концу сессии —
приложение запускается, можно залогиниться, роли работают, навигация есть.

> **Статус: ✅ выполнено.** Все 13 пунктов реализованы. Детализация по шагам —
> в `session-1-step-1..9-*.md` (у каждого баннер «Реализовано» с ссылками на код).

## 1. Инфраструктура проекта

- [x] Создать Flutter-проект, подключить Firebase (Auth, Firestore, Storage, Functions)
- [x] Зафиксировать стек: Riverpod, go_router, DI, freezed
- [x] Структура папок (core / features / shared / data / domain / presentation)
- [x] Firebase Emulator Suite для локальной разработки

## 2. Авторизация и роли

- [x] Регистрация / вход по email+паролю
- [x] Восстановление пароля, подтверждение email
- [x] Модель пользователя + профиль (коллекции `users`, `profiles`)
- [x] 3 роли (админ/преподаватель/студент) + редирект на нужный интерфейс после входа

## Результат сессии

Приложение запускается на web/mobile, проходит регистрация и вход,
пользователь по роли попадает на свой dashboard, навигация между разделами
работает (с заглушками). Фундамент готов для наполнения фичами в Сессии 2.
